# GeoTwin

Explainable AI and GIS prototype for compound urban heat and flood-risk prioritization (Chennai, India).
Built for Hack for Social Cause, VBYLD 2027 (theme: AI, GIS & Emerging Technologies).

This is a decision-support prototype. It is not a flood warning or forecasting system.

## Setup (Linux)
    git clone https://github.com/Faasilmigdaad-19/geotwin-climate-risk.git
    cd geotwin-climate-risk
    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    streamlit run app.py
